Possible Datasets:
------------------

1. Official dataset:

url: http://www.cellpose.org/dataset
citation:
description: 540 fluorescent rob images (512 × 383 pixels) with 16-bit masks as a training data. 

2. Breast Cancer Dataset

url: https://zenodo.org/records/4034976
citation: Guillaume Jacquemet. (2020). Combining StarDist and TrackMate example 1 - Breast cancer cell dataset (Version 1) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.4034976
description: Contains a StarDist example training dataset, a test dataset, and the StarDist model generated using ZeroCostDL4Mic. 72 Paired microscopy images (fluorescence) and corresponding masks. 1024x1024 (Pixel size: 634 nm). 16-bit for fluorescence and 8 and 16-bit for the masks.

3. Flow chamber dataset

url: https://zenodo.org/records/4034939
citation: Gautier Follain, & Guillaume Jacquemet. (2020). Combining StarDist and TrackMate example 3 - Flow chamber dataset (Version 1) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.4034939
description: Contains a StarDist example training dataset, a test dataset, and the StarDist model generated using ZeroCostDL4Mic. 1024x1024 pixels, 8-bit for brightfield images and 8 and 16-bit for the masks. 58 training instances.

4. Glioma C6 dataset for cell segmentation

url: https://zenodo.org/records/15083188
citation: Ilyukhin, D., Malashin, R., Pashkevich, S., Volkov, A., Yachnaya, V., Denisov, A., & Mikhalkova, M. (2025). Glioma C6 dataset for cell segmentation (Version 1.1) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.15083188
description: Training and test images of Glioma C6 cells imaged using phase-contrast microscopy for the task of cell segmentation. 2592 × 1944 pixels, 8-bit. 31 training instances.

5. SegPC-2021-dataset

url: https://www.kaggle.com/datasets/sbilab/segpc2021dataset
citation: Anubha Gupta, Ritu Gupta, Shiv Gehlot, Shubham Goswami, April 29, 2021, "SegPC-2021: Segmentation of Multiple Myeloma Plasma Cells in Microscopic Images", IEEE Dataport, doi: https://dx.doi.org/10.21227/7np1-2q42.
description: Segmentation of Multiple Myeloma Plasma Cells in Microscopic Images. The dataset consists of a total of 298 images.
